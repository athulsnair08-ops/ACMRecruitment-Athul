# Data Refinery

## Dataset
Students Performance in Exams dataset.

## Cleaning Steps

1. Loaded the raw dataset using Pandas.
2. Checked all columns for missing values.
3. Handled missing values where necessary.
4. Checked for duplicate records.
5. Removed duplicate records using `drop_duplicates()`.
6. Verified that no duplicate records remained.
7. Verified that the cleaned dataset contained no unintended missing values.
8. Saved the cleaned dataset as `cleaned_students_performance.csv`.

## Tools Used
- Python
- Pandas
- Google Colab
