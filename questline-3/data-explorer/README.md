# Data Explorer

## Dataset
Students Performance in Exams dataset from Kaggle.

## Tools Used
- Python
- Pandas
- Google Colab

## Analysis Performed
- Loaded the dataset using Pandas.
- Checked the dataset shape.
- Listed all columns.
- Checked data types.
- Checked for missing values.
- Generated summary statistics for numerical columns.

## Observations
- The dataset contains student information and exam scores.
- It contains both categorical and numerical data.
- Missing values were checked using `isnull().sum()`.
- Summary statistics were generated using `describe()`.
