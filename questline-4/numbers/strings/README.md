# String Algorithms

## 1. Valid Palindrome
**LeetCode 125**

Removed non-alphanumeric characters, converted the remaining characters to lowercase, and compared the string with its reverse.

- Time: O(n)
- Space: O(n)

## 2. Zigzag Conversion
**LeetCode 6**

Simulated moving down and up through the rows while placing each character in its appropriate row.

- Time: O(n)
- Space: O(n)

Both solutions were successfully accepted on LeetCode.
