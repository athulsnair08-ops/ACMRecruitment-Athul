# Number Algorithms

## 1. Palindrome Number
**LeetCode 9**

Reversed the number digit by digit using `%` and `//`, then compared it with the original number.

- Time: O(n)
- Space: O(1)

## 2. Integer to Roman
**LeetCode 12**

Used Roman numeral values in descending order and repeatedly selected the largest possible value.

- Time: O(1)
- Space: O(1)

Both solutions were successfully accepted on LeetCode.
