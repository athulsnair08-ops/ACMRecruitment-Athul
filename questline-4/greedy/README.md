# Greedy Algorithms

## 1. Lemonade Change
**LeetCode 860**

Tracked $5 and $10 bills and used the best available combination to give change.

- Time: O(n)
- Space: O(1)

## 2. Assign Cookies
**LeetCode 455**

Sorted the children and cookies, then matched each child with the smallest suitable cookie.

- Time: O(n log n + m log m)
- Space: O(1)

Both solutions were successfully accepted on LeetCode.
